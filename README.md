# scoop-tokensave

[Scoop](https://scoop.sh) bucket for [tokensave](https://github.com/aovestdipaperino/tokensave) and related Windows tools.

## Install

```powershell
scoop bucket add tokensave https://github.com/aovestdipaperino/scoop-tokensave
scoop install tokensave
```

## Manifests

| Manifest | Description |
|---|---|
| `tokensave` | Code intelligence tool that builds semantic knowledge graphs from source code |
| `tokensave-beta` | Beta channel of tokensave |
| `brutop` | Bruto Pascal IDE |

The [scoop-bucket](https://github.com/aovestdipaperino/scoop-bucket) repository carries the same `tokensave` manifests and is the one updated alongside each release.
